The ID of the Notion page where highlights will be saved as sub-pages. Find it in the page URL after the page title.

Setup Instructions

  1. Go to Notion Integrations and create a new integration
  2. Give it a name (e.g., "LLM Clipper") and select your workspace
  3. Copy the Internal Integration Token (starts with secret_)
  4. Create or choose a Notion page to store your highlights
  5. Click the ... menu on that page and select "Add connections" → add your integration
  6. Copy the page ID from the URL (the string after the page title, before the ?)
  7. Paste both values above and save
